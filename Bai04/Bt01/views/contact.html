HOW IT WORKS

Quy trình xử lý dữ liệu

Cách Frontend giao tiếp với Backend Express Server.

01

Nhập thông tin

Người dùng nhập tên, email và nội dung lời nhắn.

02

Kiểm tra dữ liệu

Kiểm tra các trường bắt buộc, định dạng email và độ dài.

03

Gửi Request

JavaScript gửi yêu cầu POST đến đường dẫn /contact.

04

Nhận Response

Express xử lý và trả về kết quả dưới dạng JSON.

contact-api.js 
fetch("/contact", {
    method: "POST",

    headers: {
        "Content-Type": "application/json"
    },

    body: JSON.stringify({
        name: "Demo User",
        email: "demo@example.com",
        message: "Hello BAO.DEV!"
    })
})
.then(response => response.json())
.then(data => console.log(data));
